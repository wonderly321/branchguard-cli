# Collect early user feedback

Track first-wave BranchGuard feedback after `v0.3.1`.

## Goals

- Find 10 real small-team users.
- Help at least 3 teams install BranchGuard in a real repository.
- Collect feedback on PR comments, `fail-on-risk`, HTML artifacts, webhooks, and weekly matrix reports.

## Questions

- Did BranchGuard catch a conflict earlier than your normal workflow?
- Is `fail-on-risk: high` a good default?
- Is the PR comment useful enough?
- Which integration matters most: Feishu, DingTalk, WeCom, Slack, or GitLab?
- Would a team report, private CI package, or single binary be worth paying for?

## Notes

Please include:

- Team size.
- Git host: GitHub, GitLab, Gitee, or other.
- Whether you used local CLI or CI.
- What blocked first-time setup, if anything.
- One feature you expected but did not find.
