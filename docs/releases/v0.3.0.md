# BranchGuard v0.3.0

BranchGuard v0.3.0 turns the CLI into a small-team CI workflow tool.

## Upgrade

```bash
npm install --global branchguard-cli@0.3.0
branchguard doctor
```

## Highlights

- Report files with `--output <file>` for `check` and `matrix`.
- PR comment creation/update from the GitHub Action via `comment: "true"`.
- Directory risk summaries in JSON, text, Markdown, and HTML reports.
- Recent-contributor hints from `git log` for faster owner routing.
- Risk-based Action failure policy with `fail-on-risk: any`, `high`, or `never`.
- Self-contained HTML reports for CI artifacts.
- GitHub Action `output` input for writing report files.
- Team webhook notifications for generic, Feishu, and DingTalk payloads.
- GitHub Action `mode: matrix` for scheduled weekly branch conflict reports.

## Examples

HTML report:

```bash
branchguard check origin/main HEAD --html --output branchguard-report.html
```

Pull request Action:

```yaml
- uses: wonderly321/branchguard-cli@v0.3.0
  with:
    base: origin/main
    head: HEAD
    format: markdown
    fail-on-risk: high
    comment: "true"
    github-token: ${{ github.token }}
```

Weekly report Action:

```yaml
- uses: wonderly321/branchguard-cli@v0.3.0
  with:
    mode: matrix
    base: origin/main
    format: html
    output: branchguard-weekly-report.html
    fail-on-risk: high
```
