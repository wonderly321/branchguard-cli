# BranchGuard v0.3.1

BranchGuard v0.3.1 is a documentation and packaging patch focused on Chinese-speaking users.

## Upgrade

```bash
npm install --global branchguard-cli@0.3.1
branchguard doctor
```

## Changes

- Localized the primary `README.md` into Chinese for domestic developer adoption.
- Added `README.en.md` for English readers.
- Included both README files in the npm package.
- Kept CLI commands, options, and GitHub Action inputs in English for developer familiarity.
