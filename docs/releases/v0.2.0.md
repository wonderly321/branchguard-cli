# BranchGuard v0.2.0

BranchGuard v0.2.0 makes the CLI usable in CI workflows.

## Upgrade

```bash
npm install --global branchguard-cli@0.2.0
branchguard doctor
```

## Highlights

- GitHub Action wrapper via `uses: wonderly321/branchguard-cli@v0.2.0`.
- GitHub Action inputs for `base`, `head`, `format`, `fail-on-conflict`, `summary`, and `working-directory`.
- GitHub Action outputs for `exit-code`, `conflict`, `report`, and `summary-written`.
- Markdown output for `branchguard check` and `branchguard matrix`.
- GitHub Actions step summary support.
- GitLab CI merge request example.
- Modern `git merge-tree --write-tree` conflict output parser hardening.

## Examples

Markdown report:

```bash
branchguard check origin/main HEAD --markdown
```

GitHub Action:

```yaml
- uses: wonderly321/branchguard-cli@v0.2.0
  with:
    base: origin/main
    head: HEAD
    format: markdown
```

GitLab CI:

```yaml
script:
  - branchguard check "origin/$CI_MERGE_REQUEST_TARGET_BRANCH_NAME" HEAD --markdown
```
