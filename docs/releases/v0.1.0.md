# BranchGuard v0.1.0

BranchGuard v0.1.0 is the first public npm release.

## Install

```bash
npm install --global branchguard-cli
branchguard doctor
```

## Highlights

- `branchguard init`
- `branchguard doctor`
- `branchguard check <base> <head>`
- `branchguard matrix --base <base>`
- JSON output for automation
- `.branchguard.json` configuration
- Configurable high-risk patterns
- Configurable ignore patterns
- Git 2.37 fallback for older `git merge-tree` output
